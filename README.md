🌿 Pest Attack Prediction System Based on Sensor Data and Leaf Images

AI-powered IoT system for early pest attack prediction using environmental sensor data and leaf image analysis.

📖 Overview

This project was developed as an academic Project-Based Learning (PBL) initiative to support early detection of pest attacks on agricultural crops. The system combines environmental sensor data with computer vision techniques to improve the accuracy of pest prediction and provide real-time monitoring.

The application integrates IoT devices, machine learning models, and a web-based dashboard to assist users in monitoring crop conditions and identifying potential pest attacks.

✨ Features
🌱 Real-time environmental sensor monitoring
📷 Leaf image-based pest detection
🤖 AI-powered pest prediction
📊 Dashboard for monitoring prediction results
📄 Export prediction reports to PDF
📈 Detection history management
🔍 Model confidence visualization
👨‍💼 Admin management dashboard
